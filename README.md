# GNN Bootcamp

A learning and practice repository for Graph Neural Networks (GNNs), graph representation learning, and graph-based machine learning workflows.

## Overview

This repository is organized as a bootcamp-style collection of notes, examples, and experiments related to graph neural networks. It is intended to support learning, experimentation, and future portfolio development.

## Repository Category

**Original / Learning Portfolio**

This repository represents my own learning path and practical work around graph neural networks. It is part of my public GitHub portfolio.

## Topics

- Graph Neural Networks
- Graph representation learning
- Node classification
- Link prediction
- Graph classification
- Fraud and anomaly detection with graphs
- PyTorch Geometric / DGL experiments

## How to Use

Clone the repository:

```bash
git clone https://github.com/alimohammadi44/GNN_Bootcamp.git
cd GNN_Bootcamp
```

Install dependencies when a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Run notebooks or scripts depending on the experiment you want to study.
